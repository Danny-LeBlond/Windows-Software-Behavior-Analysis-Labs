# Windows Software Behavior Analysis Labs

Static and dynamic analysis of training executables and DLLs in a Windows virtual machine. The documents record observed behavior, analysis results, and supporting screenshots.

## Static analysis — Week 2

- `Module 2 Week 2 Assignment Perform a preliminary static analysis.docx` — PEStudio analysis of Lab01-01.exe, including file properties, imports, strings, and possible indicators.
- `Module 2 (Week 2), Lab 1.1 and Lab 1.3.docx` — Analysis of Lab01-01.exe, Lab01-01.dll, and Lab01-03.exe.

## Dynamic analysis — Week 3

- `Module 2 Week 3 Assignment Use of Dynamic Analysis Tools.docx` — Analysis of Lab03-01.exe, including before-and-after Windows Registry comparisons with Regshot.
- `Module 2 Week 3 Lab 3.2 and Lab 3.4.docx` — Observations from testing Lab03-02.dll and Lab03-04.exe with dynamic analysis tools.

## Tools and environment

Windows virtual machine, PEStudio, Regshot, Process Monitor, and Process Explorer.

The training executables and DLLs are not included in this repository.
